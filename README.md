## 🚀 How to Install on Your Phone

### Option 1: Direct Android APK Install (Recommended for Android)
1. Download [AnirudhAgency.apk](https://github.com/Dhruvkittur/order_invoice/releases/download/v1.0.0/AnirudhAgency.apk) directly on your Android phone.
2. Tap the downloaded file in your Notifications or Downloads folder.
3. If prompted, allow "Install from unknown sources" and tap **Install**.
4. The **ANIRUDH AGENCY** app icon will appear in your phone's app drawer!

### Option 2: 1-Tap PWA Install (Android & iPhone — No APK Needed)
1. Open [https://dhruvkittur.github.io/order_invoice/](https://dhruvkittur.github.io/order_invoice/) in **Google Chrome** (Android) or **Safari** (iPhone).
2. **On Android**: Tap the green **"Install App on Device"** button or Chrome's menu (`⋮`) → **Install app**.
3. **On iPhone**: Tap the **Share** button (📤) → **Add to Home Screen** → **Add**.
4. The app opens fullscreen like a native app and works 100% offline!

## ✨ Features
- **100% Offline Capability**: Runs with zero internet connection via IndexedDB and Service Worker caching.
- **Fast 2-Letter Item Autocomplete**: Instant catalog search matching brand, size, packing, and category.
- **Excel Catalog Import & Dual-Sheet Export**:
  - Import items from `.xlsx` with auto column header mapping.
  - Export orders with dual sheets: Orders Summary and Detailed Line Items.
  - Direct WhatsApp & Email sharing via Web Share API.
- **Responsive Mobile UI**: Native Android & iOS look and feel with swipe gestures and touch-friendly controls.
